About

What is njX UI?

A CSS component library that lives on a CDN. DaisyUI vibes without the Tailwind dependency: semantic classes, ready-made blocks and themes that switch with one attribute. Pair it with Alpine.js when you need state — njX ships the look, you ship the page.
